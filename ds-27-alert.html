Alert

arrow_back arrow_forward

An inline banner that asks the user to look at something, optionally with one action. Norbielink has a single alert: a neutral surface with the brand gradient as the only accent. The alert itself has no severity variants — it is always neutral. Severity lives elsewhere: status badges carry the product’s teal / amber / red status map, and destructive confirmation uses the red dialog on the Alert Dialog page.

Installation

Built with pure HTML and CSS. Include ds-shared.css in your project.

pnpm add @norbielink/ds

Don't

Tint the surface by severity. Norbielink has no info / success / warning / error alert.
Use a filled Material icon — the alert icon is a 2px stroke outline.
Add a left colour bar. The banner has a full 1px border, not a 3px rail.
Give the alert more than one action.
