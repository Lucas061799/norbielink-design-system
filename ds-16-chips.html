Chips

arrow_back arrow_forward

Norbielink has one chip: a neutral pill that lists a value — an affiliation, a carrier, a tag. It is not interactive, carries no icon and has no close button. When a list is too long it is truncated with a +N more chip, which is the only interactive variant.

Chip

Seen in the Affiliations column. Five values are shown and the rest collapse into the overflow chip, which tints razz on hover.
