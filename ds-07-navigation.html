Navigation

arrow_back arrow_forward

Norbielink has one navigation surface: a fixed 220px sidebar that is white in light mode. There is no top bar, no collapsed rail and no gradient-filled pill. Both rest and active items keep a white fill — what changes is the border, which becomes the brand gradient, and the active item adds a soft purple glow.

Sidebar

Logo, account button, divider, scrolling nav, then a pinned footer. The whole column is 220px wide with a 1px #F3F4F6 right border.

Nav item states

Three states, not four — there is no disabled nav item. Hover and active share the same gradient border; only the glow, the icon colour and the label colour separate them.

rest border: 1px transparent · icon #9CA3AF · label #6B7280
hover gradient border · no glow · colours unchanged
active gradient border + glow · icon #A614C3 · label #2D3653

The gradient border

Hover and active do not fill the item. They paint the 1px border with the brand gradient by layering a padding-box fill over a border-box gradient, and the active item adds 0 0 8px rgba(166,20,195,.4). This is the only place in the product that uses the treatment.

There is no collapsed sidebar. The column is always 220px. The collapse controls elsewhere in the product belong to detail panels, not to navigation.
There is no application top bar. Each page draws its own 71px header with a 22px / 400 title and a 0.87px #F3F4F6 rule.
The logo, the Norbie face and the bottom wash are image assets, not drawn in CSS — norbielink-logo.png (swapped for -dark in dark mode), norbieface.png and sidebar-bg.png. Icons are lucide outlines at stroke-width 2, not the Material set used by this documentation site.
In dark mode the column becomes #191D35 with a rgba(255,255,255,.12) right border, and the item fill becomes linear-gradient(to bottom, #191D35 0%, #582A75 48%, #9D37BC 100%) — the only place the product fills a nav item.
