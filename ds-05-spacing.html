Space

arrow_back arrow_forward

Norbielink uses a 4px base unit spacing scale. All padding, margin, and gap values must be multiples of 4. This creates visual rhythm and ensures pixel-perfect alignment across components.

Layout grid

Norbielink layouts use a 12-column grid with a 16px gutter at 1440px wide (1920px for full-bleed screens). The sidebar occupies 2–3 columns; content fills the remaining columns.
