Shape

arrow_back arrow_forward

Eight radii, and nothing between them. Every corner in the product is one of these values — there is no 20px, no fractional radius, and no continuous ramp.

Scale

4px
Checkbox
6px
Status chip · segmented-control segment
8px
Secondary button · toolbar button · filter track · alert action · toast pill
9px
Toast icon disc — the one odd value, and it is deliberate
10px
Primary button · input
12px
Card · alert banner · menu · toast · KPI tile
16px
Dialog · large panel
9999px
Badge · avatar · dot · switch track · filter pill

Choosing a radius

Controls scale with their size: a 16px checkbox takes 4px, a 20–32px chip takes 6px, a button takes 8–10px.
Containers take 12px; only a dialog or a full panel goes to 16px.
9999px is for things that read as a token — badges, avatars, dots, switch tracks.
If a value is not on this list, it is a mistake. The DS previously shipped 5px, 7px, 9px, 13px, 14px, 15px, 18px and 20px across 60 rules.
