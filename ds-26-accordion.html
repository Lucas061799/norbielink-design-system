Accordion

arrow_back arrow_forward

Norbielink has one accordion: the correspondence list on a quote or policy record. A row carries a timestamp and a reference number; opening it reveals the message on a white card inset inside the row. The toggle is a plus / minus, never a chevron, and it is always #A614C3.

Correspondence list

Rows are independent — opening one does not close the others. The closed row is a tinted #FAFAFB block; the open body is a white card inset by 16px on each side.

Open state is held in a Set, so any number of rows can be open at once. There is no single-open variant.
The toggle does not animate. Chevrons in this product always mean a dropdown opens below — using one here would read as a select. That is why the accordion uses plus / minus instead.
This is not the same as Collapsible, which wraps a single bordered panel, or the sidebar’s nav group on Navigation, which reveals links rather than content.
In dark mode the row becomes rgba(255,255,255,.03), the body card #191D35, borders rgba(255,255,255,.08), and the reference turns #4ECDC4 — the only token that changes hue rather than lightness.
