Combobox

arrow_back arrow_forward

Norbielink’s combobox is the table column filter. It is not a single-value picker — it is a searchable, multi-select checklist that opens from a column heading, with Select All at the top and Reset Filter at the bottom. For picking one value from a short list the product uses a plain select instead.

Column filter

The trigger is the column heading itself, with a small caret. Both heading and caret turn #A614C3 while any value is selected, so an active filter is visible without opening the panel.

The checkbox here is not the one on Checkbox: it is smaller, has a 1.5px border, and shows a bare tick instead of filling with the brand colour. It exists only inside this panel.
Selecting nothing and selecting everything mean the same thing — an empty set is treated as “no filter”, which is why Reset Filter clears the set rather than ticking all of it.
The search box filters the option list only. It never creates a value, so this is a filter, not a tag input or a free-text entry.
There is no keyboard navigation, no highlighted option and no empty state — a search that matches nothing simply renders an empty list between the two dividers.
