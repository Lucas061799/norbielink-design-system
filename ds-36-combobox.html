Combobox

arrow_back arrow_forward

Two comboboxes ship, and they have nothing in common but a search box. The column filter is a multi-select checklist that opens from a table heading; the address autocomplete is a single-value typeahead backed by a remote geocoder. For picking one value from a short fixed list the product uses a plain select instead.

Column filter

The trigger is the column heading itself, with a small caret. Sortable columns sit beside it carrying a double arrow instead — same 11px uppercase type, different affordance. Both heading and caret turn #A614C3 while any value is selected, so an applied filter reads without opening the panel.

Address autocomplete

The second combobox is a true single-value typeahead, used for the street field on a client record. Typing queries a remote geocoder and picking a suggestion fills street, city, state, ZIP and country in one go — so the control writes five fields, not one.

Hovering a row moves the keyboard cursor rather than painting a separate hover state, so the two never disagree about which row Enter would pick.
The panel renders only when there is at least one result. There is no “no matches” state and no spinner inside the list — the … in the field is the only loading signal.
This is the only control in the product that reaches a third-party service while you type.

The checkbox here is not the one on Checkbox: it is smaller, has a 1.5px border, and shows a bare tick instead of filling with the brand colour. It exists only inside this panel.
Selecting nothing and selecting everything mean the same thing — an empty set is treated as “no filter”, which is why Reset Filter clears the set rather than ticking all of it.
The search box filters the option list only — it never creates a value, so this is a filter, not a tag input. The address autocomplete below is the opposite: its field is the value.
There is no keyboard navigation, no highlighted option and no empty state — a search that matches nothing simply renders an empty list between the two dividers.
