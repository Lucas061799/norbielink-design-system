Loading & Progress

arrow_back arrow_forward

Norbielink has no progress bar. A DOM and bundle sweep finds no role="progressbar", no determinate bar and no percentage readout anywhere in the product. Long actions are shown by spinning the icon on the control that started them.

The loading pattern

The control keeps its place, its icon spins, and its label changes. Nothing is added to the layout, so the page does not shift.

Specs

PropertyValue
IndicatorThe button’s own 14×14px icon — no separate element
Animation0.9s linear infinite, rotating to -360deg — counter-clockwise
Icon colour#6B7280 · unchanged while loading
LabelSwaps to the present participle, e.g. Refresh → Refreshing…
Disabledcursor: not-allowed while the action runs
Do not add a progress bar, a percentage or a blocking overlay. For content that is still arriving, use Skeleton.
The rotation is negative. A clockwise spin reads as a different component.
