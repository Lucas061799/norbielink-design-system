Buttons

arrow_back arrow_forward

Five button roles ship. Only one is filled with the brand gradient — the rest are a neutral outline, bare text, or an icon. The gradient primary is also the only button whose hover is a brightness shift; everything else fills with a tint.

The five roles

Counted across the whole app: 32 gradient primaries, ~35 outlined secondaries, 7 danger solids, 63 icon buttons and 5 text links, plus the full-width auth primary below. There is no ghost button — an action without a box is a text link, not a borderless one.

Primary gradient fill · hover brightness(1.08)
Secondary 1px border · hover fills #F9FAFB
Danger solid #EF4444 · #DC2626 when discarding edits
Text gradient-clipped text · underline at offset 3px
Icon padding 6px · radius 6px · 16px glyph

Primary sizes

Three paddings, one type size. The 12px/600 label never changes — only the box around it does.

SizePaddingUsed for
Small6px 12pxInside a toolbar or a table header
Medium8px 16pxThe default — most actions
Large9px 17pxThe main action on a panel, e.g. Add Activity

States

Disabled is the same everywhere: half opacity and a not-allowed cursor. The fill is never swapped for grey.

Auth primary

The sign-in screens use a wider, full-width variant of the primary — the only button in the product that carries a resting shadow.

A handful of one-offs exist and are deliberately not roles — each appears once or twice and should not be reached for: a brand-purple outline on Generate Code (1px #A855F7) and a PDF action (1px #A614C3); a tonal fill on Book Roll (brand at 8–10% inside rgba(166,20,195,.22) at radius 12px); and a white CTA on the Marketplace promo card (#5C2ED4 text, 0 2px 8px rgba(0,0,0,.10)). The last two also rise 1px on hover — the only buttons in the product that move. Use a role above instead.
Two roles lift on hover — tonal and inverse rise 1px and deepen their shadow. That is the only place a button moves, and the inverse is the only button with a resting shadow outside the auth screens.
Primary hover is a brightness filter, not a darker gradient or a shadow — 23 sites use 1.08 and 19 use 1.10. Everything else hovers by filling with #F9FAFB.
Only the auth primary has a resting shadow. Elsewhere a primary sits flat, including in dialogs.
The icon button is by far the most common — 63 sites against 32 gradient primaries. Most actions in this product are icons in a row, not labelled buttons.
