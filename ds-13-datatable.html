Data Tables

arrow_back arrow_forward

Data tables display structured information for entities like Agencies and Users. They include a search toolbar, gradient filter pills, a tab bar with icon controls, sortable columns, status badges, and minimal pagination.

Anatomy

A data table has five zones: toolbar (search + actions), filter pills, tab bar, data rows, and footer. Each zone has distinct typographic and spacing treatment.

ZoneNameDescription
AToolbarSearch input + Search button, Add New action, Drafts toggle
BFilter pillsAll · Appointed · Unappointed — active pill has gradient border + gradient text
CTab barAgencies · All Users · Affiliations — active tab underline uses brand gradient; icon buttons on right
DData rows☆ star · 13px semibold name · agency code in #A614C3 · muted location / affiliation · user count · status badge
EFooterGray-50 background — per-page dropdown (left) · ← gradient page# → (center) · Page X of Y (right)

Pagination

Only the current page number is shown, with gradient fill. Arrow chevrons navigate prev/next. Footer background is gray-50.
