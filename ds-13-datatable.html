Anatomy

A data table consists of four zones: toolbar, header row, data rows, and footer. Each zone has distinct typographic and spacing treatment.

A
Toolbar — filters, search, export
B
Header row — 11px Uppercase Bold · sortable · gray-50 bg
C
Data row — 13px Regular · hover: gray-50 · link cells in Teal · status cells use badge
D
Footer — per-page selector · page counter · pagination controls

Pagination

Teal active page indicator. Arrow buttons use gray. Pagination shows a window of up to 5 pages.
